# Security and privacy

Do not upload, send, or commit any of the following:

- QQ AppSecret, AppID together with its secret, or webhook credentials
- LLM, TTS, cloud, or VPN tokens
- AstrBot data directory, databases, chat logs, dashboard users, or backups
- private reference audio, voice models, checkpoints, or generated recordings
- public IP whitelist addresses if they identify a private deployment

This template binds the dashboard to 127.0.0.1 by default. Do not expose port 6185 or GPT-SoVITS port 9880 to the public Internet unless you understand and secure the full network path.

Use only voices, models, images, and personas you are authorized to use. A non-commercial use case does not automatically create redistribution or impersonation rights.
