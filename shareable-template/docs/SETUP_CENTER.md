# 可视化配置中心

双击项目根目录的 `Setup-Center.cmd`，即可使用图形界面完成本机安装、状态检查、文本人格包和语音包导入，以及日常启动；不需要手动输入 PowerShell 命令。

## 最短流程

1. 在 **基础环境** 页安装 Docker Desktop，并点击 **启动 AstrBot**。
2. 在 **QQ 官方机器人** 页打开 QQ 开放平台，创建自己的机器人。事件订阅选择 WebSocket；把当前公网出口 IPv4 填进服务器 IP 白名单。
3. 打开 AstrBot 的 **机器人** 页，创建 QQ 官方机器人适配器，并在该页面填写自己的 AppID 与 AppSecret。
4. 打开 AstrBot 的 **模型提供商** 页，填写自己的模型服务地址、模型名称和 API Key，选择为默认对话模型。
5. 可选：在 **人格包** 页选择文本人格 ZIP，点击 **安全准备并打开人格页**。向导会验证文件、复制系统提示词并打开 AstrBot 人格页面；新建人格时使用日志显示的 Persona ID，粘贴并保存。随后回到向导点击 **设为默认人格**。
6. 可选：在 **本地语音** 页下载匹配运行环境、选择 GPT-SoVITS 文件夹，再导入有权使用的语音包 ZIP。
7. 在 **启动与常驻** 页点击 **日常启动**，并在 QQ 中 @机器人测试。

## 人格包安全边界

人格包是独立、纯文本的 ZIP。基础项目会检查它的清单、文件白名单、大小和 SHA-256，然后把提示词准备到剪贴板。它不会执行人格 ZIP 内的脚本，也不会直接修改 AstrBot 人格数据库或要求管理登录令牌。

通过 AstrBot 官方页面保存人格可降低版本升级时的兼容风险。最后的“设为默认人格”步骤只会备份并更新 `data/cmd_config.json` 中的默认人格 ID；请在新会话中测试，因为已有会话可能保留旧人格。

## VPN 与 IP 白名单

QQ WebSocket 不要求把家庭路由器端口暴露到公网，但 QQ 平台的服务器 IP 白名单会校验这台电脑对外访问的公网出口 IP。

- 如果白名单使用了 VPN 节点的 IP，请先连接同一 VPN 节点再启动机器人。
- 更换 VPN 节点、断开 VPN、切换网络或手机热点，可能会使出口 IP 改变；此时需要在 QQ 开放平台更新白名单。
- 点击向导中的 **检测当前出口 IP** 可查看当前值。浏览器页面本身不需要常开。

## 仍需使用者自行完成的外部事项

- QQ 官方机器人的账号、AppID、AppSecret、体验用户和 IP 白名单；
- 大模型服务账户、账单与 API Key；
- Docker Desktop、GPU 驱动和 GPT-SoVITS 本体；
- 如依赖固定出口 IP，VPN 客户端自身的登录后自动连接设置；
- 所有独立人格包、语音包或其他素材的分享范围确认。
