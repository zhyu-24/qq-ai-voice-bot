# 可视化配置中心

下载者双击项目根目录的 `Setup-Center.cmd`，即可用图形界面完成 Docker、QQ 官方机器人、大模型、可选本地语音和日常启动配置。

## 最短流程

1. 在“基础环境”页安装 Docker Desktop，并启动 AstrBot。
2. 在“QQ 官方机器人”页按步骤创建自己的机器人，事件订阅选 WebSocket，并登记当前公网出口 IPv4。
3. 在 AstrBot 的“机器人”页创建 QQ 官方机器人适配器，填入自己的 AppID 与 AppSecret。
4. 在 AstrBot 的“模型提供商”页配置自己的模型服务、模型名称和 API Key。
5. 可选：安装匹配的 GPT-SoVITS，选择其目录并导入有权使用的语音包 ZIP。
6. 点击“日常启动”，然后在 QQ 中 @机器人测试。

## 安全说明

- 不要分享 QQ AppSecret、模型 API Key、运行目录 `data`、聊天记录或日志。
- 语音包导入器校验清单与文件哈希，只使用基础项目内置导入逻辑，不执行 ZIP 中未知脚本。
- 若 QQ 平台白名单依赖 VPN 出口 IP，先连接正确 VPN 节点；更换节点或网络后请更新白名单。

详细说明见项目的 README 和各页向导文字。
