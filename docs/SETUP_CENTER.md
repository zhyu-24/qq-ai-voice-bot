# 可视化配置中心

双击项目根目录的 `Setup-Center.cmd`，即可用图形界面完成本机安装、状态检查、语音包导入和日常启动；不需要手动打开 PowerShell。

## 最短流程

1. 在“基础环境”页安装 Docker Desktop，并点击“启动 AstrBot”。
2. 在“QQ 官方机器人”页打开 QQ 开放平台，创建自己的机器人。事件订阅选择 WebSocket；把当前公网出口 IPv4 填进服务器 IP 白名单。
3. 打开 AstrBot 的“机器人”页，创建 QQ 官方机器人适配器，并在该页面填入自己的 AppID 与 AppSecret。
4. 打开 AstrBot 的“模型提供商”页，填入自己的模型服务地址、模型名称和 API Key，选择为默认对话模型。
5. 如需本地定制语音，在“本地语音”页下载匹配运行环境、选择 GPT-SoVITS 文件夹，再导入有权使用的语音包 ZIP。
6. 在“启动与常驻”页点击“日常启动”，并在 QQ 中 @机器人测试。

## VPN 与 IP 白名单

QQ WebSocket 不要求把家庭路由器端口暴露到公网，但 QQ 平台的服务器 IP 白名单会校验这台电脑对外访问的公网出口 IP。

- 如果白名单使用了 VPN 节点的 IP，先连接到同一 VPN 节点再启动机器人。
- 更换 VPN 节点、断开 VPN、切换网络或手机热点，可能会使出口 IP 改变；此时需要在 QQ 开放平台更新白名单。
- 点击向导中的“检测当前出口 IP”可查看当前值。浏览器页面不需要常开。

## 语音包安全

向导只会调用基础项目内置、受信任的导入器。它会验证 ZIP 中的 `manifest.json` 与每个模型文件的 SHA-256，再把资产复制到本地 GPT-SoVITS 目录并备份 AstrBot 配置；不会执行 ZIP 内附带的未知脚本。

语音包只适用于拥有相应使用和传播授权的素材。它不能包含 QQ 凭据、模型 API Key、聊天记录或人格素材。

## 仍需用户自行完成的外部事项

- QQ 官方机器人的账号、AppID、AppSecret、体验用户和 IP 白名单；
- 大模型服务账号、账单与 API Key；
- Docker Desktop、GPU 驱动和 GPT-SoVITS 本体；
- 如依赖固定出口 IP，VPN 客户端本身的登录后自动连接设置。
