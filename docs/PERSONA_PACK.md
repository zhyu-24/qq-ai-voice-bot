# 人格包（纯文本）

人格包是基础环境包之外的独立 ZIP，用来携带一份可分享的 AstrBot 系统提示词。它与语音包完全分开：人格包不含音频、模型权重或训练材料。

## 包内允许的内容

- `assets/system-prompt.md`：一份 UTF-8 系统提示词；
- `manifest.json`：人格 ID、显示名、文件大小与 SHA-256；
- 使用说明与发布声明。

## 包内不会出现的内容

- QQ AppID、AppSecret、模型 API Key、VPN 信息；
- AstrBot 数据库、管理员账号、聊天记录、日志；
- 语音、图片、模型权重、训练语料或可执行脚本。

## 下载者如何导入

1. 先完成基础包的 Docker、QQ 官方机器人和大模型配置。
2. 双击基础项目中的 `Setup-Center.cmd`，打开 **人格包** 页。
3. 选择人格 ZIP，点击 **安全准备并打开人格页**。向导会验证文件、把系统提示词复制到剪贴板，并打开 AstrBot 的官方人格页面。
4. 在 AstrBot 新建人格，使用日志显示的 Persona ID，粘贴提示词并保存。
5. 回到向导，点击 **设为默认人格（已保存后）**，再执行一次 **日常启动**。新建对话会使用该人格；已有会话可能仍保留先前设定。

为了兼容 AstrBot 的版本升级，导入器不会直接编辑它的人格数据库，也不会要求、记录或传递你的管理登录令牌。

## 发布者如何导出

在发布者源项目中，双击 `Export-PersonaPack.cmd`，或在配置中心的 **分享项目** 页导出。生成的 ZIP 位于本机 `release`，默认不会被 Git 提交。

发布前请自行确认文本的分享范围；非官方同人设定应明确为非官方，不应表示官方账号、官方角色扮演授权或官方背书。
